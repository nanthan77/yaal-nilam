## Changes

- Shorter Tamil-first landing page with a larger brand mark, clear navigation,
  compact Buy/Rent/Short stay search and localized loading/empty/error states.
- Responsive property cards, price and land facts, gallery controls, related
  listings, save/compare/share and a mobile inquiry bar with enough space around it.
- Compact App Store/GPT footer links; Google Play remains visibly Coming soon.
- Saved currency restores after initial client mount, preventing a server/client
  price mismatch when real listings return. Existing language/compare preferences
  and the separate currency storage key remain compatible.
- Production sample/media guards and accurate unknown values. The homepage image
  stays visibly labeled illustrative, and platform review does not certify title.
- Canonicals, private-route noindex headers, property rewrites and cache behavior
  were checked against the actual static export and Firebase Hosting.
- The reviewed release path now requires committed source and a fresh matching
  export receipt before public Hosting deployment. Generated caches were removed
  from Git tracking while keeping physical local copies.

## Inventory and remaining limits

All 11 public records inspected matched historical seed fixtures across seven
fields. They remain in Firestore but are excluded from visitor-facing inventory,
feeds, schema and property exports. There are currently **zero genuine public
listings**; do not describe fixture testing as real-property verification.
Owner-supplied listing data and photographs are needed for that coverage.

The dependency audit remains open: **12 affected package entries — 1 critical,
8 high, 2 moderate, 1 low**. The critical Next findings require server/image
features absent from this static Hosting release. This does not make the audit
clean. Exact advisories, exposure and candidate updates are in
[the dependency assessment](docs/WEB_DEPENDENCY_AUDIT_2026-09-30.md).
Patched Next versions require a separate major framework upgrade.

Email/WhatsApp delivery, genuine account authorization, analytics receipt and an
actual OS share sheet were not exercised. The share payload and fallback were
checked locally. Native app build/submission status is outside this website release.

Only `hosting:main` was published. Admin remains on release `1790702405672000`,
version `f6592bcce9195b44`, released 2026-09-29 17:20:05.672 UTC. Functions,
Firestore/Storage rules and indexes were not deployed. Existing unrelated dirty
work was preserved.
