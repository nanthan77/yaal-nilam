# Local website fonts

Inter (Latin) and Noto Sans Tamil (Tamil) are the same font families used by the
existing design. Their variable WOFF2 subsets are stored locally so production
builds do not require Google Fonts network access. Both use the SIL Open Font
License; the corresponding license files are included here.

Source: Google Fonts CSS API, retrieved 26 September 2026.
